# Task 1 - Responsive Landing Page

## Project Description

This project is a simple responsive travel landing page created using HTML and CSS.

The website is designed to introduce travel destinations and provide a clean and user-friendly layout.

## Features

* Responsive navigation bar
* Hero section with travel background image
* Explore Now button
* Popular destination cards
* Paris, Maldives and Dubai sections
* About section
* Footer with social links
* Responsive design for mobile devices

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries

## Project Files

* `index.html` - Main webpage structure
* `style.css` - Website styling and responsive design
